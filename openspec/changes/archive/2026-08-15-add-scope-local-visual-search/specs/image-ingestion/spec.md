## ADDED Requirements

### Requirement: 图片入库后必须异步启动视觉处理链
系统 MUST 在图片字节和 Meme 记录成功提交后，为当前图片 SHA-256 创建或复用视觉向量生成任务，并在上传结果中返回视觉任务标识。上传请求 MUST NOT 等待视觉模型推理，也 MUST NOT 在视觉向量成功前直接启动该图片的自动 Agent 语境任务。

#### Scenario: 单张图片成功入库
- **WHEN** 客户端上传一张合法且未重复的图片
- **THEN** 系统提交对应的视觉向量任务、返回可轮询的任务标识，并让图片立即出现在图片库中

#### Scenario: 批量图片成功入库
- **WHEN** 一次上传中的多张图片分别成功保存
- **THEN** 系统为每张成功图片分别创建或复用视觉向量任务，且不同图片的处理允许并发和跨阶段交错

#### Scenario: 视觉服务不可用
- **WHEN** 图片已经成功入库但视觉向量任务因配置缺失或服务不可用而失败
- **THEN** 系统保留图片及失败诊断，不回滚其他成功图片，也不为该图片自动提交 Agent 语境任务
