# GIF 分析

使用任务提供的原始 GIF 路径；图片附件可能只包含首帧预览。

- 检查全部帧。可按时间顺序分组展示，保持文字和动作清晰可读。
- 优化后的 GIF 子帧可能只保存局部更新。使用 ImageMagick 的 `-coalesce` 或其他支持 GIF 帧合成的工具，按透明区域、帧位置和 disposal 规则还原完整画面后观察。
- 同时观察文字变化、画面变化和时间节奏：字幕出现的顺序、动作与表情的转变、停顿、重复及循环衔接。
- 文件记录的播放延迟不一定等于所有播放器中的实际观感，尤其是极短延迟。描述节奏时区分文件时间信息与已观察到的播放表现。

例如，人物先微笑、随后掩面，字幕同时从“没事”变成“撑不住了”，摘要应保留这些变化及其先后关系。

沿用现有输出字段：动作过程和节奏写入 `summary`，原始字幕按出现顺序写入 `visible_text`，无法确认的内容写入 `uncertainties`。单帧 GIF 按静态图片分析。
