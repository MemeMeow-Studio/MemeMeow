## ADDED Requirements

### Requirement: 图片处理状态必须使用有限的公开阶段 DTO

图片处理轮询接口 MUST 只返回允许的阶段名称、状态、有限错误、warning、时间和安全标识。阶段错误、warning、恢复信息和历史记录 MUST 经过同一公开清理规则；scope、宿主路径、payload、凭据以及未经验证的数据库字段 MUST 不得出现在响应中。

#### Scenario: 图片处理阶段包含内部字段
- **WHEN** 阶段历史包含执行器绑定、绝对路径或未知状态字段
- **THEN** 轮询响应只返回公开阶段字段，未知字段被省略，非法状态收束为稳定失败状态

#### Scenario: 自动命名阶段产生可恢复 warning
- **WHEN** 自动命名因标题缺失、目标冲突或输入变化产生 warning
- **THEN** 响应只返回阶段、稳定错误、有限消息和可恢复标识，父处理任务仍按既有状态报告
