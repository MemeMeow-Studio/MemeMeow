## MODIFIED Requirements

### Requirement: 合集 ZIP 预检必须限制压缩资源和条目类型
合集导入 MUST 在任何合集、图片或成员关系写入前验证整个 ZIP。压缩包原始字节 MUST 不超过 64 MiB；成员数量 MUST 不超过 500；单成员解压大小 MUST 不超过 20 MiB；总解压大小 MUST 不超过 512 MiB；任一成员的解压大小与压缩大小之比 MUST 不超过 100:1（非空成员的压缩大小为零也必须拒绝）。系统 MUST 拒绝 ZIP64 元数据、嵌套归档、目录、符号链接、硬链接标记和其它非普通文件条目。

#### Scenario: ZIP 压缩包本身过大
- **WHEN** 客户端提交原始字节超过 64 MiB 的 ZIP
- **THEN** 系统在读取 manifest 前返回稳定的资源超限错误
- **AND** 不创建合集或写入任何图片

#### Scenario: ZIP 放大比过高
- **WHEN** 任一成员的 manifest/中央目录声明解压大小相对压缩大小超过 100:1
- **THEN** 系统拒绝整个导入
- **AND** 不读取该成员的完整解压内容或产生 durable 副作用

#### Scenario: 不安全条目被拒绝
- **WHEN** ZIP 含 ZIP64、嵌套 ZIP、目录、链接或 Unix 特殊文件条目
- **THEN** 系统返回稳定的不安全归档错误
- **AND** 不把该条目当作图片保存

### Requirement: ZIP 声明、实际内容和清理必须形成一致边界
合集预检 MUST 同时核对中央目录声明的压缩/解压大小、实际读取字节、manifest 成员大小、扩展名和 SHA-256；任何不一致 MUST 在业务写入前失败。导出读取 MUST 从受控 scope 根目录打开普通文件描述符并在读取期间保持该对象，不得因路径竞态跟随符号链接。预检或导出失败时，临时归档和临时目录 MUST 被安全清理，清理不得跟随攻击者替换的符号链接。

#### Scenario: 声明大小与实际内容不一致
- **WHEN** ZIP 中央目录或 manifest 声明的大小与实际解压字节不一致
- **THEN** 系统返回稳定的大小不一致错误
- **AND** 不创建合集、不写入图片或成员关系

#### Scenario: 导出期间路径被替换
- **WHEN** 导出成员路径在 stat 与读取之间被替换为符号链接或特殊文件
- **THEN** 系统拒绝读取该成员并清理临时归档
- **AND** 不读取 scope 根目录之外的内容
