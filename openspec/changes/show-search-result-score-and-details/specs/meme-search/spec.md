## ADDED Requirements

### Requirement: 搜索富媒体结果必须保留当次向量相似度
系统 MUST 在不改变 `results` 受控媒体 URL 数组兼容结构的前提下，为每个返回的富媒体结果关联其在当次查询中用于排序的有限余弦相似度值。该值 MUST 与同一结果的稳定 `meme_id` 绑定，并 MUST 在过滤不可访问结果和去重后仍与媒体结果一一对应。系统 MUST NOT 为查看该值重新调用 embedding 服务或执行第二次相似度查询。

#### Scenario: 返回可访问搜索结果及相似度
- **WHEN** 当前 scope 的索引已就绪且搜索产生可访问候选
- **THEN** 响应继续返回原有 `results` 媒体 URL 数组，并在对应富媒体结果中返回同一次检索产生的余弦相似度

#### Scenario: 过滤不可访问候选
- **WHEN** 排名候选中的图片已不可访问或与先前结果重复
- **THEN** 系统过滤该候选，并保持其余富媒体结果的 `meme_id`、媒体引用和相似度正确对应

#### Scenario: 查看相似度不触发重新检索
- **WHEN** 客户端在搜索完成后查看某一结果的相似度
- **THEN** 客户端使用该搜索响应携带的值，不触发额外 embedding 调用或相似度查询
