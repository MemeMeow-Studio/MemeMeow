## MODIFIED Requirements

### Requirement: 系统必须提供受控的扁平图片列表
系统 MUST 只列出当前可信数据范围图片根中的 Meme，不得提供用户可见的目录层级。列表响应 MUST 返回稳定 `meme_id`、文件名、扩展名、大小、处理状态和受控媒体引用，不得返回服务器绝对路径或目录字段。列表 MUST 支持文件名筛选、分页和确定性排序。

#### Scenario: 列出当前数据范围的图片
- **WHEN** 客户端请求图片列表并提供合法的筛选及分页参数
- **THEN** 系统返回当前可信数据范围内匹配的扁平图片列表
- **AND** 每张图片包含稳定 Meme 身份和受控媒体引用，不包含目录信息

#### Scenario: 提交已废弃的目录参数
- **WHEN** 客户端向图片列表提交 `directory` 或其他目录选择参数
- **THEN** 系统返回参数错误
- **AND** 不执行目录浏览或兼容逻辑

### Requirement: 系统必须安全地重命名图片
系统 MUST 根据稳定 `meme_id` 在当前可信数据范围的图片根中执行重命名，保留原扩展名，拒绝路径分隔符、控制字符、保留内部名称和已有文件覆盖，并在成功后返回相同 `meme_id`、新文件名和媒体引用。系统 MUST NOT 接受或返回目录标识。

#### Scenario: 重命名成功
- **WHEN** 客户端提交当前数据范围内存在的 `meme_id` 和合法且未占用的新文件名
- **THEN** 原文件在同一图片根中被重命名且扩展名保持不变
- **AND** Meme 身份与合集等逻辑关系保持不变

#### Scenario: 新文件名冲突
- **WHEN** 目标文件名已存在
- **THEN** 系统返回 `409`
- **AND** 原文件和数据库记录保持不变

#### Scenario: 新文件名非法
- **WHEN** 新文件名包含路径结构或使用内部保留名称
- **THEN** 系统返回 `400`
- **AND** 原文件和数据库记录保持不变

### Requirement: 系统必须通过媒体接口提供图片
图片预览 MUST 通过稳定 `meme_id` 的受控媒体接口读取，接口 MUST 校验 Meme 属于当前可信数据范围、数据库记录只包含扁平文件名、文件身份和指纹一致，并 MUST 使用实际文件类型返回内容类型。

#### Scenario: 预览合法图片
- **WHEN** 客户端请求当前数据范围内存在且指纹一致的 Meme
- **THEN** 系统返回图片内容及正确的媒体类型

#### Scenario: 预览非法或不存在图片
- **WHEN** 客户端请求跨范围、不存在、非扁平或指纹不一致的 Meme
- **THEN** 系统返回 `404` 或一致性错误
- **AND** 不读取其他文件

## ADDED Requirements

### Requirement: 系统必须拒绝非扁平图片库存量
系统 MUST 在 schema migration 写入扁平约束前拒绝任何非扁平 Meme 业务 key，并 MUST 在应用启动就绪检查中拒绝非扁平 Meme 记录、图片根下嵌套的受支持图片以及与数据库记录不一致的嵌套业务文件。检查 MUST 是只读的，不得自动移动、导入、重命名或删除文件。受控的内部 staging 和 quarantine key MUST NOT 被当作业务图片拒绝。

#### Scenario: 扁平图片库通过就绪检查
- **WHEN** 数据库中的全部 Meme 使用扁平文件名，图片根不存在嵌套业务图片，且内部暂存区只包含受控操作文件
- **THEN** migration 和应用就绪检查允许服务继续启动

#### Scenario: migration 发现非扁平业务记录
- **WHEN** migration 在 Meme 记录或存储操作的业务字段中发现包含路径结构的业务 key
- **THEN** migration 在执行 schema DDL 前失败并报告一致性错误
- **AND** 不修改数据库记录或文件

#### Scenario: 启动发现嵌套业务图片
- **WHEN** 应用启动就绪检查发现非扁平 Meme 记录、图片根下的嵌套受支持图片或与数据库不一致的嵌套业务文件
- **THEN** 应用拒绝进入就绪状态并报告扁平图片库不一致
- **AND** 不自动修改任何记录或文件

#### Scenario: 内部恢复文件不阻止启动
- **WHEN** `.staging` 或 `.quarantine` 中存在符合存储操作协议的受控内部文件
- **THEN** migration 和应用就绪检查不把这些内部 key 视为非扁平业务图片
- **AND** 现有恢复流程仍可处理对应操作

## REMOVED Requirements

### Requirement: 系统必须安全地创建图片目录
**Reason**: 合集成为唯一用户可见组织方式，目录会形成重复且相互冲突的分类模型。

**Migration**: 不提供迁移或兼容接口；删除目录创建端点及全部前端入口。

## RENAMED Requirements

- FROM: `系统必须提供受控的图片目录和文件列表`
- TO: `系统必须提供受控的扁平图片列表`
