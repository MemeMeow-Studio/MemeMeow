## MODIFIED Requirements

### Requirement: 图片入库后必须异步启动统一图片处理
系统 MUST 在图片字节和 Meme 记录成功提交后，为当前图片 SHA-256 创建或复用统一图片处理 job，并在上传结果中返回该 job 标识。上传请求 MUST NOT 等待视觉模型、Agent 或文本 embedding 执行完成。图片处理 job 必须遵守逐图失败隔离：其任一阶段失败不得回滚已成功入库的图片，也不得影响同批其他图片的处理。

#### Scenario: 单张图片成功入库
- **WHEN** 客户端上传一张合法且未重复的图片
- **THEN** 系统提交对应的图片处理 job、返回可轮询的 job 标识，并让图片立即出现在图片库中

#### Scenario: 批量图片成功入库
- **WHEN** 一次上传中的多张图片分别成功保存
- **THEN** 系统为每张成功图片分别创建或复用图片处理 job，且不同图片的处理允许并发和跨阶段交错

#### Scenario: 图片处理服务不可用
- **WHEN** 图片已经成功入库但其图片处理 job 因配置缺失或服务不可用而失败
- **THEN** 系统保留图片及失败诊断，不回滚其他成功图片，也不为该图片在上传请求内直接启动 Agent 或文本 embedding
