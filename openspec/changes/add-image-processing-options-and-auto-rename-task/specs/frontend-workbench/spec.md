## ADDED Requirements

### Requirement: 上传与完整重试必须复用图片处理选项对话框
工作台 MUST 在“上传所选图片”和“完整重试所有未就绪”真正提交前打开同一图片处理选项对话框。对话框 MUST 提供 `reverse_image_policy=forbid|auto` 与 `auto_name=false|true` 两项选择，且每次打开的安全默认值 MUST 为禁止联网和不自动重命名；不得沿用上一次操作中风险更高的选择。只有用户明确确认后，调用方才能把两个规范化选项与对应操作一并提交。

#### Scenario: 上传所选图片前确认
- **WHEN** 用户已选择图片并点击“上传所选图片”
- **THEN** 工作台先显示处理选项对话框，不立即上传文件
- **AND** 用户确认后，所有所选文件使用同一组规范化选项提交

#### Scenario: 完整重试前确认
- **WHEN** 用户点击“完整重试所有未就绪”
- **THEN** 工作台使用同一对话框确认选项，再发起服务端 scope 级完整重试

#### Scenario: 取消处理选项
- **WHEN** 用户关闭或取消处理选项对话框
- **THEN** 工作台不上传文件、不发起完整重试，也不改变图片或任务状态

### Requirement: 对话框必须反映联网能力并防止重复提交
工作台 MUST 使用服务端公开的能力状态决定 `auto` 是否可选。联网能力未配置、不可用或状态无法确认时，`auto` MUST 不可选择并显示稳定原因，`forbid` MUST 保持可用。提交期间，对话框及其调用入口 MUST 防止重复确认；失败时 MUST 保留用户仍可安全重试的选择，并展示与上传或完整重试相对应的错误，不得把失败请求显示为成功。

#### Scenario: 联网能力不可用
- **WHEN** 用户打开对话框且服务端报告反向图片检索不可用
- **THEN** `auto` 选项不可选择并提供原因，默认的 `forbid` 仍可确认

#### Scenario: 提交进行中再次确认
- **WHEN** 用户已经确认且对应请求仍在进行中
- **THEN** 工作台忽略或阻止后续确认，不创建重复上传或重复完整重试请求

#### Scenario: 提交返回处理选项冲突
- **WHEN** 服务端因活动 Job 的冻结选项不同而拒绝某个目标
- **THEN** 工作台显示稳定的冲突反馈和受影响目标，不把它概括为已完成处理

### Requirement: 处理选项对话框必须满足键盘、焦点和窄屏约束
对话框 MUST 具有可感知的标题和字段标签，打开时 MUST 将焦点移入对话框并限制在其中，关闭后 MUST 将焦点返回触发入口。用户 MUST 能使用键盘选择选项、确认和取消，Escape 取消不得提交请求；在窄屏和内容放大时，选项、状态与操作不得重叠或超出可操作区域。

#### Scenario: 仅使用键盘完成确认
- **WHEN** 用户通过键盘打开处理选项对话框并修改选择
- **THEN** 用户可以辨认当前值、确认提交或取消，且焦点不会进入被遮挡的工作台内容

#### Scenario: 在移动端显示服务不可用原因
- **WHEN** 窄屏设备上的 `auto` 选项不可用且带有原因
- **THEN** 原因和两个主要操作仍完整可读、可聚焦且互不遮挡

### Requirement: 工作台必须区分自动重命名警告与核心处理失败
图片库和任务视图 MUST 展示条件性的 `auto_rename` 阶段：未启用时显示为已跳过，启用且运行时关联 `image_auto_rename` 叶子 Task，可降级命名失败时显示非阻塞警告，目标或执行身份失效时显示停止 Job 的失败。Job 已成功且 `has_warnings=true` 时，工作台 MUST 同时表达核心处理已完成和自动重命名未完成，并提供受限的自动重命名阶段重试入口；不得把 Job 伪装成整体失败或从通用 Task 重试入口重试该叶子 Task，也不得把不可降级失败伪装成 warning。

#### Scenario: Job 带自动重命名警告完成
- **WHEN** Job 状态为 `succeeded`、`has_warnings=true`，且自动重命名叶子 Task 为 `failed`
- **THEN** 工作台显示核心处理已完成、文件名保持可用及自动重命名警告
- **AND** 用户可从图片阶段动作重试自动重命名

#### Scenario: 自动重命名未启用
- **WHEN** Job 的 `auto_name=false`
- **THEN** 工作台将自动重命名阶段显示为已跳过，不显示不存在的叶子 Task 或失败动作
