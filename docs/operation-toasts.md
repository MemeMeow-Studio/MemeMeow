# 操作提示

一次性操作结果通过 `useToast()` 显示，应用根组件提供唯一的 `ToastHost`。成功提示在三秒后自动关闭，错误和需要用户处理的警告保留到手动关闭。连续操作的结果分别显示；普通页面切换保留已经产生的提示。

表单校验、首次读取和轮询故障、任务进度及逐项处理结果继续保存在对应页面。工作区使用 `error` 事件报告操作错误，使用 `loadError` 事件报告持续读取故障。提示保留原有错误原因和公开信息限制。

`useModalDialog` 将 toast 容器移动到当前模态框内部，使关闭按钮进入模态框的键盘范围。按 Alt+T 可以进入提示区域，提示不会主动改变用户的输入焦点。移动端容器适配安全区域，长消息完整换行显示。

提示显示在页面右下方，手机端预留底部导航和安全区域。连续提示超过可用高度时，提示区域可以滚动。

账户适配层在退出或切换身份时调用 `clearToasts()`。请求所属组件卸载后，其提示入口停止产生新提示。

`frontend/src/components/ToastHost.test.ts` 使用真实组件和计时器验证生命周期、连续提示、账户提示清理及模态框访问。
