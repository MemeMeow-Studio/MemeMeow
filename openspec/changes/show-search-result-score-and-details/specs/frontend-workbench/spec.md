## ADDED Requirements

### Requirement: 搜索结果必须提供相似度详情并复用图片库详情
检索工作区 MUST 在每个图片结果旁提供“查看详细信息”入口。该入口 MUST 打开轻量对话框并以“余弦相似度”展示当次搜索响应中的 embedding 相似度值；界面 MUST 将其表述为排序参考而非身份、正确概率或置信度。轻量对话框 MUST 提供打开同一 Meme 图片库详情的动作，并 MUST 复用现有图片库详情界面。轻量对话框与图片库详情 MUST 依次替换，不得形成叠加的模态层。

#### Scenario: 查看搜索结果相似度
- **WHEN** 用户点击某个结果旁的“查看详细信息”
- **THEN** 系统打开轻量对话框，展示该结果当次检索的余弦相似度值及其参考性质

#### Scenario: 进入图片库详情
- **WHEN** 用户在轻量对话框中点击“查看图片库详情”
- **THEN** 系统关闭轻量对话框，并使用同一 `meme_id` 打开复用的图片库详情界面

#### Scenario: 复制与详情操作保持独立
- **WHEN** 用户点击结果图片或独立的详情入口
- **THEN** 点击图片继续复制原图，而点击详情入口只打开详情，不意外触发复制

#### Scenario: 键盘关闭并恢复焦点
- **WHEN** 用户通过键盘打开或关闭搜索结果详情
- **THEN** 对话框遵循既有模态焦点约束，关闭后焦点返回触发该详情的控件

#### Scenario: 窄屏查看结果详情
- **WHEN** 用户在 320px 及以上的窄屏设备查看搜索结果和详情
- **THEN** 图片、详情入口、相似度文案和对话框操作均完整可读且页面不产生水平溢出
