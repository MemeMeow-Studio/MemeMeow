## Purpose

为公网服务定义不可信 Agent 结果、任务历史和图片处理诊断的统一公开数据边界，确保敏感信息命中时整体拒绝或省略，而不是依赖各个接口调用方自行猜测可返回字段。

## ADDED Requirements

### Requirement: Agent 结果必须满足公开字段和敏感数据边界

系统 MUST 只接受规定的 Agent 顶层字段，并递归检查字符串、嵌套对象和列表。结果中出现未允许字段、凭据原值或常见编码变体、URL userinfo、敏感查询参数、私网或内部 URL、绝对路径或内部执行字段时，系统 MUST 整体拒绝结果，不得部分写入语境。

#### Scenario: Agent 结果包含未知字段
- **WHEN** Agent 结果在规定字段之外包含 scope、工具诊断或其他字段
- **THEN** 后端以稳定 schema 错误拒绝完整结果，且任务不写入任何语境内容

#### Scenario: Agent 结果包含敏感 URL 或凭据
- **WHEN** Agent 结果文本包含带 userinfo 的 URL、访问令牌查询参数、私网地址或已配置凭据的原值/编码变体
- **THEN** 后端以稳定边界错误拒绝完整结果，不把原始值写入任务错误或 API 响应

### Requirement: 公开任务和图片处理响应必须使用显式 DTO

系统 MUST 按任务类型投影公开结果，并为任务摘要、恢复历史、图片处理阶段、warning 和 error 只保留稳定字段。公开响应 MUST 不包含原始任务 payload、scope 身份、宿主路径、执行绑定或未经收窄的历史 JSON；无法验证的历史字段 MUST 被省略或转换为安全的失败状态。

#### Scenario: 查询包含脏历史结果的任务
- **WHEN** 持久化任务结果包含内部模型配置、绝对路径或未知结构
- **THEN** 任务接口只返回该任务类型允许的字段，敏感或未知字段不出现在响应中

#### Scenario: 查询包含脏阶段和恢复记录的图片处理任务
- **WHEN** 阶段状态、错误消息、时间或恢复标识来自损坏的旧记录
- **THEN** 图片处理接口返回有限的公开阶段 DTO，非法字段被省略，恢复能力按绑定缺失 fail-closed
